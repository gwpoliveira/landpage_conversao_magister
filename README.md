# 🏫 Landing Page de Alta Conversão - Instituto Magister de Ensino (Teresina-PI)

Landing page institucional e de captação de matrículas de alta conversão para o **Instituto Magister de Ensino** em Teresina, Piauí.

## 🚀 Tecnologias

- **Framework**: Next.js 15 (App Router, React 19)
- **Tipografia & Estilização**: Tailwind CSS v3.4 + Plus Jakarta Sans & Inter
- **Ícones**: Lucide React
- **Validação & Segurança**: Zod + Schema.org JSON-LD para SEO local
- **Identidade Visual Oficial**: Extraída diretamente de `logo.png` (Azul Real `#134889` e Âmbar Ouro `#F5AC1D`)

## 📦 Como Rodar Localmente

```bash
# Instalar dependências (já instaladas)
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build

# Iniciar servidor de produção
npm start
```

O servidor iniciará em `http://localhost:3000`.

## 📱 Recursos de Conversão

- **Hero com CTAs Duplos & Card de Contato Rápido**
- **Bento Grid dos 4 Ciclos Pedagógicos (Infantil, Fund. I, Fund. II, Ensino Médio)**
- **Formulário Multi-Step em 3 passos com integração direta ao WhatsApp da Secretaria**
- **Modal de Agendamento Dinâmico por Ciclo**
- **FAQ Sanfona Anti-Objeções**
- **Botão Flutuante do WhatsApp com Micro-Interação**
- **Schema.org estruturado para o Google Local em Teresina-PI**
